# Zodiac Calendar

For everybody like me who cannot remember the range of the zodiac signs. Just a simple calendar file with the dates/ranges.

## Usage

- Put the calendar file somewhere on a webspace and memorize the path.
- In Google calendar add a new calendar by URL and enter the memorized path.
- For your mobile:
  - Wait a few minutes until this calendar is available.
  - For the calendar:
    - Enable it by activating the checkbox.
    - Synchronize it in it's properties.
- Have fun!
